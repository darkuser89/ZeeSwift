# ZeeSwift Compatibility List

This page tracks game compatibility with **ZeeSwift**, a Zeebo HLE for ARM-based Macs using Metal 4.

## Status Legend

| Status | Description |
|---|---|
| ✅ Perfect | Runs without known issues. |
| 🟢 Playable | Playable from start to finish, with minor issues. |
| 🟡 In-Game | Reaches gameplay, but has significant issues. |
| 🟠 Boots | Starts and reaches menus or intro screens, but not gameplay. |
| 🔴 Broken | Does not run correctly or crashes. |
| ⚪ Untested | Not tested yet. |
